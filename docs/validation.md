# 验证范围

日期：2026-11-09。

- 当前标题技能：核对 YAML 入口、名称、引用文件及无数据情况下的行为约束；删除缺少独立复核材料的具体统计数据。
- 代表性样例检查：输入“作者用脚本整理了 20 篇笔记，尚未开源，没有计时”，可以输出“我用脚本整理了20篇笔记：过程与限制”；不能输出“一键提效10倍，我把工具开源了”。这验证规则与事实边界的一致性，不是实际账号效果或自动评测。
- 历史源码：逐文件 SHA-256 对照来源提交；百度网盘及 Kimi 快照内容不改，公众号快照仅额外附原 LICENSE。
- Gitleaks 扫描历史快照与原 skills Git 历史，无发现；扫描不保证不存在所有隐私或权利问题。
- 仅支持文档描述的逐目录复制安装，不声称递归安装器会排除 legacy。未修改用户的已安装技能。

未验证：真实微信公众号草稿写入、百度账号登录和文件操作、Kimi CLI 编排、灵汐付费 API、剪映运行、各 Agent 的实际加载行为，以及阅读量或商业效果。历史项目的测试与构建本次未重新运行。
