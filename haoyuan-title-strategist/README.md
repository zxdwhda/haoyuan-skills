# 公众号标题策略

根据完整文章生成、批评和排序中文标题。适合教程、工具实践、评测与观点文章；不需要 API Key，不发布文章，不保证阅读量。

## 安装

克隆本仓后，只复制 `haoyuan-title-strategist` 文件夹到所用 Agent 的 Skills 目录。例如 Codex 的 `~/.agents/skills/`，Claude Code 的 `~/.claude/skills/`。若已有同名技能，先比较并保留自定义修改，不直接覆盖。不要复制整个仓库或 `legacy/`。

纯 Markdown 指令，无平台专用执行代码；需要支持 SKILL.md 的 Agent。安装后重新加载技能或启动新会话。

## 示例

“使用 haoyuan-title-strategist，阅读下面完整文章，给出主标题和两个备选，检查是否夸大：……”

输入正文、目标读者及可选历史数据；输出标题候选、比较理由及事实风险。没有正文证据时，不添加实测、开源、数字和结果；没有历史数据时，不声称关键词具有流量优势。
