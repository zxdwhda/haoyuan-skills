# 错误码对照表

## 本地策略错误

这些错误由 Skill CLI 在调用 OpenAPI 之前拦截,通常带有更友好的中文提示。

| 错误类 | 触发场景 | 用户操作建议 |
|---|---|---|
| `AuthError` | token 缺失 / 过期 / refresh 失败 / 授权码格式错误 | 运行 `pan.cjs login` 重新登录 |
| `ScopeError` | 路径超出 sandbox 或 full 白名单 | 检查路径前缀,或 `pan.cjs scope` 切换模式 |
| `PolicyError` | 硬删除四级保护未通过 | 仔细阅读提示,如需软删除则去掉 `--hard` |
| `ConfigError` | config.json / token.json 损坏或不可读 | 检查 `~/.config/baidu-drive-skill/` 下文件权限与格式 |
| `HttpError` | 网络断开、5xx、超时 | 检查网络,稍后重试 |

### PolicyError reason 速查

| reason | 含义 |
|---|---|
| `targets-empty` | 未传入任何删除目标 |
| `too-many` | 单次删除超过 100 项 |
| `wildcard-unexpanded` | 路径含 `*` `?` 未展开 |
| `bad-path` | 非法路径(非字符串或不以 `/` 开头) |
| `root-path` | 试图删除 `/`、`/apps` 或沙盒根 |
| `token-expiring` | token 剩余 < 60 秒,避免删到一半失效 |
| `phrase-mismatch` | L3 逐字确认串不匹配 |
| `user-chose-soft` | L4 用户选择改走软删除 |

## 百度 OpenAPI errno

百度网盘 OpenAPI 的业务错误码。HTTP 状态码通常为 200,但响应体中 `errno != 0`。

| errno | 含义 | 常见场景 |
|---|---|---|
| 0 | 成功 | — |
| -6 | 身份验证失败 | access_token 无效或权限不足 |
| -7 | 远端文件名错误 | 路径含非法字符或格式不对 |
| -8 | 文件名已存在 | mkdir / upload 时目标已存在 |
| -9 | 文件不存在 | ls / download / rm 时路径不存在 |
| -10 | 云端容量已满 | 上传时空间不足 |
| 2 | 参数错误 | 请求参数缺失或格式错误 |
| 6 | 不允许接入用户数据 | 应用未开通 netdisk 权限 |
| 10 | 创建文件失败,目录已存在同名文件 | mkdir 幂等时正常,非幂等时报错 |
| 12 | 部分文件已存在 | 批量操作中部分项冲突 |
| 105 | 链接错误 | 分享链接不正确 |
| 110 | access_token 已失效 | 需重新登录或 refresh |
| 111 | access_token 已过期 | 同上 |
| 2131 | 该分享不存在 | 分享已被取消或过期 |
| 13045 | 不允许转存自己的分享 | 文件已在你的网盘中 |
| 31021 | 网络错误 | 百度服务端临时问题 |
| 31023 | 参数错误 | 类似 errno=2 |
| 31024 | 没有申请上传权限 | 应用未开通上传权限 |
| 31034 | 请求频率过高 | 触发限流,降低并发后重试 |
| 31062 | 文件名无效 | 含特殊字符或过长 |
| 31064 | 不允许访问该目录 | 权限不足或路径越界 |
| 31066 | 文件不存在或已删除 | 类似 errno=-9 |
| 31075 | 同名文件已存在 | 类似 errno=-8 |
| 31202 | 文件不存在 | 类似 errno=-9 |
| 31299 | 第一个分片大小不正确 | 上传分片尺寸不符合预期 |
| 31363 | 分片缺失 | 上传过程中某分片未成功提交 |
| 31364 | 分片大小超出限制 | 单分片超过用户等级上限(普通 4MB) |
| 31390 | access_token 失效或权限不足 | 类似 errno=110/111 |
| 31399 | 调用太频繁 | 类似 errno=31034 |
| 42000 | 服务异常 | 百度服务端临时故障 |
| 42213 | 没有该接口权限 | 应用未勾选 netdisk 权限 |
| 42214 | 调用频率超限 | 类似 errno=31034 |

## 排查流程

1. **先看错误前缀**
   - `认证失败:` → token 问题,`pan.cjs login`
   - `策略拒绝:` → 删除保护未通过,检查 `--hard` 用法
   - `配置错误:` → 本地 JSON 损坏
   - 无前缀,只有 errno → 百度服务端返回,查上表

2. **token 相关(errno 110/111/31390/-6)**
   ```bash
   pan.cjs status          # 检查过期时间
   pan.cjs login           # 重新登录
   ```

3. **频率限制(errno 31034/31399/42214)**
   - 降低并发数:修改 `config.json` 的 `concurrency.uploadParts` / `downloadChunks`
   - 等待 30-60 秒后重试

4. **文件不存在(errno -9/31066/31202)**
   - 确认路径拼写(区分大小写?百度网盘不区分文件名大小写,但路径校验区分)
   - sandbox 模式下确认是否在 `/apps/<appName>/` 下
   - 用 `pan.cjs ls <父目录>` 确认文件确实存在

5. **上传失败(errno 31299/31363/31364)**
   - 检查分片大小:普通用户单分片 ≤ 4MB
   - 检查断点续传状态文件是否损坏:删除 `~/.config/baidu-drive-skill/uploads/*.json` 后重试
