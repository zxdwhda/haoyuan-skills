# 公众号文章写作风格参考

## 对标账号

「悦漫先生」— 情感治愈类公众号

## 参考文章：《多夸，少管，适合所有关系》

### 原文结构

```
图&文/悦漫先生

很多关系变差，是从管太多开始的。
关系近的人，总忍不住想纠正对方，这里说一句，那里说一下，话里话外都是为你好。
可说多了，对方听着烦，自己也累，原本亲近的人，反而越处越远。

人性如此，听一句认可，比挨十句训管用。
好听的话谁都愿意听，多夸上几句，对方心里舒坦了，关系自然就跟着好了。
夸不是哄，也不是客套，是把对方做对的地方，真诚说出口，让人知道自己是被看见的。

管得多，操碎了心，对方却只觉得压抑。
每个人都有自己的活法，看着再不顺眼，那也是别人自己的人生。
管多了，对方憋着一肚子气，自己也跟着累，到头来什么都没改成，感情倒是一点点磨没了。

倒不如把挑剔放下，把管换成赞赏。
夸和不管，看着像两件事，其实是一回事，承认他人的优点，也相信和尊重他人的选择。

人与人之间，从来没那么复杂，多一份信任，少一句指点。
试图去控制别人，本来就是一场费力又不讨好的较量。

关系里最难得的，从来不是谁管得了谁，而是在一起时，都觉得松弛。
多看对方的好，少插手对方的事，不管是亲人、朋友，还是伴侣，处起来都不容易散。
多些捧场，少些指手画脚，不是教人虚伪，是把别人的事情还给别人，也让自己的人生更加轻松。
```

### 风格要点

| 维度 | 特征 |
|------|------|
| 标题 | 简洁有力，一句话点明主题，有记忆点 |
| 句长 | 10-25 字为主，偶尔更短 |
| 段落 | 3-5 句一段，段落之间有呼吸感 |
| 语气 | 像朋友聊天，不说教 |
| 文风 | 温暖治愈，有洞察力，偶尔有金句 |
| 结构 | 递进式：问题 → 原因 → 态度 → 解法 → 升华 |
| 词汇 | 口语化但不随意，有文学感 |
| 禁忌 | 不用"本文""小编""欢迎留言"等套话 |

### 排版习惯

- 段与段之间空一行
- 每段 80-150 字
- 全文控制在 400-800 字
- 有节奏感：短句 → 短句 → 稍长句 → 金句
